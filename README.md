# Apresentação ViaGate

Mini site em formato de apresentação institucional da ViaGate.

## Executar localmente

```bash
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## Navegação

- Scroll vertical
- Setas do teclado
- Page Up / Page Down
- Botão inferior para avançar

## Assets

As logos oficiais ficam em `assets/`. As áreas marcadas como imagem são placeholders previstos para receber imagens finais sem alterar a estrutura da apresentação.
